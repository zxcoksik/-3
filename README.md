Сайт RESONANCE — многостраничный премиальный сайт кураторской студии винила. Общие элементы (шапка с меню, подвал, прелоадер, модальное окно заявки) подключаются на всех страницах через js/layout.js, поэтому навигация и оформление единые по всему проекту.

Главная (index.html) — основная страница. Она задаёт первое впечатление о бренде и направляет пользователя дальше по сайту. Здесь крупный hero-блок с заголовком, кратким описанием студии, кнопками перехода в каталог и открытия формы заявки, а также декоративный элемент в виде пластинки. Ниже размещены четыре карточки-навигации с краткими подписями к разделам «О нас», «Коллекция», «Процесс» и «Отзывы».

О нас (about.html) — дополнительная информационная страница. Её задача — рассказать, чем отличается RESONANCE от обычного магазина: кураторский подход, работа с редкими изданиями, доставка и мероприятия для комьюнити. На странице есть вводный заголовок, развёрнутый текст о философии студии, четыре карточки преимуществ и кнопка «Оставить заявку».

Коллекция (catalog.html) — основная коммерческая страница. На ней пользователь выбирает и просматривает товары. Размещена сетка из шести карточек винила в формате маркетплейса: фото, статус наличия, название, исполнитель, характеристики, рейтинг, цена, кнопки «В корзину» и «Подробнее». По клику на изображение открывается lightbox для детального просмотра.

Процесс (process.html) — дополнительная страница, которая снимает вопросы о том, как устроена работа со студией. Она показывает путь клиента в пять шагов: заявка, поиск и проверка пластинки, упаковка, доставка и финальный этап «первый spin». Внизу есть призыв оставить заявку через модальное окно.

Отзывы (reviews.html) — дополнительная страница социального доказательства. Она укрепляет доверие к сервису через отзывы клиентов: четыре текстовые карточки с оценками, именами и ролями (коллекционер, DJ, критик, продюсер), переключаемые слайдером.

Модальное окно «Оставить заявку» — не отдельная страница, а общий элемент на всех разделах. Оно открывается из меню, подвала и с ряда страниц. В форме собираются имя, контакт, тип обращения (заказ, вопрос по заказу, сотрудничество и др.) и текст сообщения; после отправки показывается подтверждение.
